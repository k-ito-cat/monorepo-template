# Error Policy

## この文書の役割

この文書は、error response の正本を API 契約と実装に置く前提で、コードだけでは共有しづらい判断だけを補足するための文書である。  
response schema の詳細は zod schema と OpenAPI を正本とし、この文書では責務分担と未決事項だけを扱う。  

## 基本方針

- エラーレスポンスの共通形は API 契約として定義する
- FE の分岐は `message` ではなく、HTTP status と機械判定用の値で行う
- FE 表示文言と API の内部事情は分ける
- 内部例外や SQL エラーはそのまま返さない
- ログに残す情報と API 応答で返す情報は分ける

## この文書に残すこと

- FE と API の責務分担
- `code` を持つか、何を分岐キーにするか
- `message` を誰向けに使うか
- validation error の `details` の扱い
- ログ / 監視 / 応答の境界
- 未決事項
