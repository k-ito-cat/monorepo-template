# Glossary

## この文書の役割

この文書は、プロダクト、UI、API、DB スキーマで使う語彙の正本を定義するための仕様書である。  
ここでは、業務概念の名称、利用者向け表示名、実装上の対応関係、禁止する言い換えを扱う。  

## 運用ルール

- UI 表示名と API 名は、ここで定義した概念の対応関係を基準にそろえる
- 新しい業務概念を追加する場合は、先にこの文書へ追加してから実装や画面へ反映する
- 既存概念の別名を増やさない
- 実装都合の略語や内部用語を、そのまま UI 表示名に使わない
- DB スキーマ名は、業務概念との対応関係が追えることを優先し、UI 表示名へ無理に一致させない
- UI 上の語彙変更だけを理由に DB スキーマ名を変更しない
- `item` や `row` のような語は、業務概念名ではなく汎用 UI 単位の説明に限定して使う
