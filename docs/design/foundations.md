## 装飾

- 角丸のルール:
- 境界線と影のルール:
- アイコンのルール: アイコンは補助として使い、主要な意味をアイコンだけに依存させない
- アイコンセットのルール: Material Symbols、Lucide、Feather、Phosphor など、一般的な UI icon set の標準的な図像を既定で使う
- 一貫性のルール: 同一画面内で意味が同じ操作は同じ図像を使い、近い意味の操作でも別責務なら別図像を使う
- 既定運用のルール: 標準的な図像がある対象は、個別に指示がなくてもアイコン併用を前提にデザインする
- 選定のルール: 特定コンポーネントごとの固定対応表は原則持たず、意味が自然に伝わる標準図像を icon set から選ぶ
