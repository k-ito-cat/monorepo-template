# UI Patterns

## この文書の役割

この文書は、画面をまたいで再利用する UI パターンを定義するための文書である。  
ここでは、モーダル、シート、トースト、インラインメッセージ、空状態、ローディング、確認 UI などを扱う。

## UI パターンの原則

- 実務上ありえる状態だけを採用する
- 意味差は明確に伝える
- 色面は情報上必要なら使ってよい
- ただし奇抜な演出やグラデーションは避ける

## パターン一覧

- Modal
- Sheet / Drawer
- Toast / Snackbar
- Inline Message
- Empty State
- Loading
- Dropdown / Popover
- Confirm UI
